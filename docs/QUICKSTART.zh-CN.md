# DealLens 快速体验（30 秒）

## 这是什么

DealLens 是一个"让投资协议动起来"的轻量网页工具：上传协议结构化数据（JSON），即可交互式查看条款关系图谱、动态 Cap Table，模拟触发回购/业绩对赌等条款后股权结构与各方权利义务的变化，并支持"修改前 / 修改后"对比演示。

## 快速体验

1. 双击 `DealLens.html`（推荐 Chrome / Edge 浏览器）
2. 点击「导入协议 JSON」，选择 `sample_seriesA.json`
3. 点击各模块，触发回购/对赌情景，观察 Cap Table 与权利义务变化

## 分析自己的协议

1. 在 AI 助手中安装 `deallens-extract` 技能
2. 把协议文件发给 AI，说："请用 deallens-extract 提取这份协议"
3. 将 AI 输出的 JSON 保存为 `.json` 文件
4. 在 `DealLens.html` 中点击「导入协议 JSON」，选择该文件

## 隐私与脱敏

- DealLens 完全在本地浏览器运行，协议数据不上传任何服务器
- 提取技能支持脱敏模式：自动泛化协议方名称、身份信息、联系方式等可识别信息，金额等商业数据保持原样以保证可视化价值
- 如需对外演示，建议始终使用脱敏模式或演示数据

## 免责提示

本工具用于辅助理解协议结构，不构成法律意见。重要决策请咨询专业律师。
